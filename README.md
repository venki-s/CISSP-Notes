# CISSP Notes 📘

Personal, chapter-wise CISSP revision knowledge base based primarily on the **ISC2 CISSP Official Study Guide (10th edition)**, with independently written explanations and references to other authoritative sources as needed.

## Study workflow

1. Review the Official Study Guide chapter and supply draft notes/excerpts.
2. Consolidate into clear, original Markdown explanations, examples, and tables. Preserve accuracy and exam-specific nuances.
3. Revise from the consolidated note.
4. Complete 20 chapter questions, record performance, and fold missed concepts back into notes.
5. Test with new, mixed-domain questions before scheduling the exam.

## Scope and source policy

- This is an **independently authored summary**, not a reproduction of the textbook. Do not commit large verbatim excerpts, commercial question banks, answer keys, or proprietary course materials.
- Track the source title, chapter or section, and edition where possible.
- Distinguish textbook wording from practical security implementation where needed.
- Maintain a single authoritative note per chapter; link to shared quick-reference material instead of duplicating it.
